## Wesley's Data Prep Suite

Wesley's Data Prep Suite is a Python-based data preparation application built with Streamlit and Pandas. It was my first data preparation project, developed to simplify the process of cleaning, transforming, and assessing datasets before analysis.

### Key Features

* **CSV and Excel Support:** Upload datasets in CSV and Excel formats.
* **Data Preview:** Inspect datasets before applying cleaning operations.
* **Automated Cleaning:** Remove duplicate records, drop completely empty columns, handle missing values using statistical methods, and standardize text.
* **Manual Cleaning:** Choose specific cleaning operations, including handling missing values, removing duplicates, trimming whitespace, converting text to lowercase, and dropping selected columns.
* **Data Quality Reporting:** Compare missing values, duplicate records, row counts, and column counts before and after cleaning.
* **Data Type Inspection:** Review column data types to better understand dataset structure.
* **Performance Metrics:** View the number of records processed, records removed, and time taken for cleaning.
* **Download Cleaned Data:** Export the cleaned dataset as a CSV file.

### Technology Stack

* Python
* Streamlit
* Pandas
* NumPy
* OpenPyXL

### Project Objective

The goal of this project is to make routine data preparation easier, more accessible, and more efficient, particularly for datasets that need cleaning before analysis or visualization.

This project represents an early step in my journey into data analytics and data engineering, demonstrating practical experience with data manipulation, missing-value handling, duplicate removal, and data quality assessment.
